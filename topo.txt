CLI (entry-point): security-app
  Ví dụ:
    security-app data/canonical_ubuntu_24.04_lts.csv 

cli.main
  └─ parse_file -> [parse_csv | parse_json | parse_xml]
  └─ run_all_rules
       ├─ _pre_extract_rules ─┬─ extract_all_commands
       │                       └─ deny_reason
       ├─ _prepare_tasks
       ├─ Executor.submit(_worker) ── run_command ── [_run_once, _to_result, deny_reason]
       └─ _merge_and_log ── RunLogger.log_rule_result ── mask_secrets
  └─ compute_stats ── print_report

Luồng xử lý chính:
1. CLI nhận input → detect file type → chọn parser phù hợp
2. Parse rules từ file → extract commands từ check text
3. Kiểm tra safety policy → phân loại allowed/denied commands
4. Chạy concurrent execution của allowed commands
5. Gộp kết quả → ghi log (rotation, 20 file) → tính toán thống kê
6. Hiển thị báo cáo trên terminal
