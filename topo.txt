# ------------------------------------------------------------
# CLI (entry-point): security-app
# ------------------------------------------------------------
# Chính sách sudo mặc định:
#   - Mặc định YÊU CẦU quyền root và sẽ tự re-exec với sudo nếu cần.
#   - Có thể tắt bằng ENV SECURITY_APP_REQUIRE_SUDO=0|false|no|off.
#
# Ví dụ nhanh:
#   security-app data/canonical_ubuntu_24.04_lts.csv \
#     --logs-dir logs \
#     --workers 8 \
#     --proc \
#     --timeout 15 \
#     --retries 1 \
#     --top 10
#
# Tham số:
#   input                : Đường dẫn file checklist (CSV/JSON/XML)
#   --logs-dir           : Thư mục gốc chứa run logs (mặc định: logs)
#   --workers            : Số worker tối đa (mặc định: tự chọn)
#   --proc               : Dùng ProcessPool (mặc định: ThreadPool)
#   --timeout            : Timeout mỗi lệnh (giây; 0/None = không giới hạn)
#   --retries            : Số lần thử lại (không tính lần chạy đầu)
#   --top                : Số item tối đa ở "Top failing rules" (mặc định 10)
#
# Log & rotation:
#   - Mỗi rule → 1 file: logs/<run>/rule-XXX_<safe_title>.log
#   - Tự xoay vòng thư mục run, chỉ giữ lại N run mới nhất (LOG_ROTATE_KEEP=20).

# ------------------------------------------------------------
# Luồng xử lý chính (CLI)
# ------------------------------------------------------------
# 1) CLI nhận input → detect file type → chọn parser (CSV/JSON/XML)
# 2) Parse rules → extract commands từ check text (marker mặc định: "$ ")
# 3) Safety policy: phân loại allowed / denied (deny_reason)
# 4) Lập kế hoạch task:
#    - _pre_extract_rules()   → [(idx, rule, allowed[], denied[])]
#    - _prepare_tasks()       → tasks (per_command/per_rule), agg, pending
# 5) Pilot run + auto-tune workers:
#    - _pilot_execute()       → chạy tuần tự N task mẫu → sample durations
#    - auto_guess_workers()   → chọn số worker phù hợp (thread/process)
# 6) Chạy song song phần còn lại:
#    - ThreadPool/ProcessPoolExecutor.submit(_workers)
#    - Thu kết quả từng phần, khi rule đủ chunk → _merge_and_log() + RunLogger.log_rule_result()
# 7) Hoàn tất → compute_stats() → print_report() trên terminal
#
# Bảo mật & riêng tư log:
#   - secrets.mask_secrets(): che thông tin nhạy cảm (password/token/Bearer …)
#   - logger chỉ ghi per-rule (không sinh summary JSON/CSV), phù hợp yêu cầu hiện tại.
